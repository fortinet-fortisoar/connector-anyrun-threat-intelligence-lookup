### The following enhancements have been made to the ANY.RUN Threat Intelligence Lookup connector in version 1.1.1:

- Enhanced the result cards to provide a more consistent and intuitive user experience across the following ANY.RUN Threat Intelligence Lookup Pluggable Enrichment playbooks:
    - Domain > ANY.RUN Threat Intelligence > Enrichment
    - File > ANY.RUN Threat Intelligence > Enrichment
    - File/Domain/IP/URL > ANY.RUN Threat Intelligence > Enrichment
    - File Hash > ANY.RUN Threat Intelligence > Enrichment
    - IP > ANY.RUN Threat Intelligence > Enrichment
    - URL > ANY.RUN Threat Intelligence > Enrichment
- The following improvements are made to the result cards:
    - Standardized verdict color accents to make analysis results easier to identify:
        - Red - Malicious
        - Yellow - Suspicious
        - Gray - Unknown/No data
        - Green - Whitelisted
    - Renamed the action button in the enrichment_summary Description field for pluggable enrichment from `Click` to `Open ANY.RUN` to make its purpose clearer.
    - Removed the background color for the action button for a cleaner and more consistent interface.
